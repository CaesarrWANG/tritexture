1. 设计

部分做法理由
tokenVAE 表 latent 中每个被占用的 (锚点, 槽位) 一个 token，内容为 3 角点 × 16 通道 = 48 维；空槽不生成空槽的后验已等于先验 (μ≈0, σ=1)，无需建模；token 数 ≈ 面数
结构由几何给出锚点、格子、槽位全部由 mesh 算出，DiT 只填内容生成时 mesh 已知，与图像 DiT 的像素网格同等地位
每 token 条件角点几何、到锚点位移、法向、锚点位置编码、槽位 one-hot、UV 岛随机编码、图像回投颜色与 VAE 共用同一套地址系统
注意力自注意力 + RoPE-6D（位置 + 法向）+ 按头的距离核阶梯 + 同 UV 岛偏置 + 8 个全局寄存 token；每层图像交叉注意力局部一致性和全局色板分开处理
目标流匹配（速度），latent 按维度标准化；t 一半 logit-normal 一半均匀，SD3 时间平移 3覆盖高噪声段（布局在这里决定）
附加损失平均色子空间加权 ×5；接缝损失 ×10：用冻结 VAE 解码预测的干净 latent，比较跨边颜色跳变与真值让模型学会面间连续
采样50 步 Euler，无分类器引导强度 4；可选接缝引导

2. 迭代过程

版本改动关键结果结论
v1按面 token + 几何条件 + 流匹配从纯噪声采样 9 dB，从 t=0.7 出发 30 dBt>0.95 训练时几乎采不到，采样第一步就偏
v2按维度标准化 latent；t 混合分布 + 时间平移去噪正常，样本面内正常但相邻面颜色无关（相邻色差 0.10，真值 0.013）缺的是面间相关性
v3注意力加距离核阶梯 + 寄存 token + 累积 2一致性收敛快一倍，但停在 0.045
v4平均色子空间加权几乎无改善latent 的平均色子空间本就平滑（相邻/随机比 0.21），粗糙的是面内细节维度
v5（取消）几何无关 VAElatent 平滑度不变（0.476 对 0.469）几何不是 latent 粗糙的原因
v6UV 岛随机编码（GLB 索引缓冲的连通块）7.5k 相邻色差 0.034，比 v4 15k 还低UV 岛解释了真值 75% 的颜色方差；第一个明显有效的改动
v7同 UV 岛的注意力偏置与 v6 相同（0.030）
采样实验降温 0.9 / 接缝引导降温：一致性到真值，但面内细节减半；引导强度 3：接缝 0.007、细节保留不一致产生于高噪声段的布局决策
v8接缝损失 ×1，按 (1−t) 加权接缝 0.044 → 0.035方向对但慢：(1−t) 压低了关键的高噪声段
v9接缝损失 ×10，各噪声等权相邻色差 0.020、接缝 0.027、色彩分布与细节都与真值吻合无条件生成可用；加强度 1 的引导后接缝到真值水平
v10图像条件：6→4 视角渲染 + DINOv2 交叉注意力采样 PSNR 11.6 → 14.3跟随条件但很松：网络要自己找每个面在图上的位置
v11每面在各视角的可见像素平均色回投为条件20.0 dB单色物体几乎精确，彩色物体颜色对上
v1228 格点逐点回投 + 6 视角（加顶/底）峰值 23.0 dB面内图案也能传进来
全规模91 点 VAE、≤ 3 万面、16 卡、v12 配方25k 步 19–20 dB，去噪 29.95进行中

3. 无条件生成：面间一致性

只给几何时生成结果对真值的 PSNR 没有意义（生成的是另一种合理纹理），所以用三个与真值内容无关的统计量：相邻面平均色差、全局颜色分布宽度、跨共享边的颜色跳变（接缝）。

5. 展示案例：与 VAE 页相同的 10 个 held-out mesh
