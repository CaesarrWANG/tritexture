单变量微调对照（A–E）与 PBR VAE

两组实验：（1）从 1/8192 切分主线的 100k 权重出发，各改一个变量再训 30k 步，看输入采样点、格点 IO、更细切分、混合采样有没有增益；（2）在同一套配方上加入金属度和粗糙度，从头训一个 5 通道的 PBR VAE 到 100k；（3）把 PBR VAE 从 100k 续训到 200k，放开坍缩通道的 KL 并加 EMA。

1. 结论

  • A–E 都没有超过对照 B。统一重评（同 32 个 mesh、三套网格）里，A、C、D、E 相对 B 在 −0.3 到 0 dB 之间，没有一组为正。91 点输入、格点 IO、1/16384 训练、混合采样都不是瓶颈。
  • 切分的收益在推理时就能拿到。同一个 B，评测网格从 1/8192 换到 1/16384 就涨 0.6 dB；用 1/16384 重训（D）反而低 0.1 dB。
  • TRELLIS.2 纹理 VAE 基线明显更好：同样的点、同样的指标，val32 面积 PSNR 26.80 对 C5VAE_100k_anneal 的 24.63；10 个展示案例的 albedo 渲染 PSNR 平均 32.3 对 27.2（见 3.3b、3.5）。
  • 续训到 200k（放开坍缩通道的 KL + EMA）：held-out 63 面积 PSNR 26.09（100k 24.60、100k + 退火 25.12），albedo 26.66，金属度 34.63（超过 TRELLIS.2）；val32 EMA 25.33，第一次超过 const（25.08）。100k 时 64 个 latent 通道只有 20 个在用，放开其余 44 个的 KL 后全部重新启用（信息随后也从仍收 KL 的通道迁移过去）；EMA 在 115k 时就追平了 10k 余弦退火（3.7 节）。
  • 续训 200k → 300k，KL 和后验采样全部去掉（进行中（242k / 300k 步））：val32 EMA 从 200k 的 25.33 到 242k 的 25.53（albedo 25.86 → 26.04）；通道消融显示 64 个通道里 7 个承担主干、约 8 个有少量信息、13 个是死的且不会自己复活（3.8 节）。
  • 推理时加密锚点（救护车单例，3.9 节）：同一个模型不重训，锚点从 8192 加到 32768，整体 +2.6 dB、纹理面 +2.7 dB；只在纹理区多放 2048 个锚点，纹理面就 +2.3 dB。latent 数量是推理时的容量旋钮。
  • 推理时按纹理细分面、锚点不变（3.10 节）：纹理面只 +1.0 dB，远小于加锚点的 +2.7；两者叠加（32768 锚点 + 均匀 1/65536 切分）全部面 28.44（基线 24.80）。瓶颈在 latent 侧。
  • 单个 latent 的作用范围（3.11 节）：attention 和直接贡献都只覆盖锚点周围一小片面，拿掉一个 token 全局最多掉 0.03 dB；latent 的容量靠密度，不靠少数关键 token。
  • PBR VAE 退火后（100k + 10k）：val32 总计 24.63，albedo 25.19，金属度 32.38，粗糙度 31.72 dB；比 100k 分别高 0.38 / 0.22 / 1.79 / 1.04 dB。
  • PBR VAE 100k：val32 总计 24.25，albedo 24.97，金属度 30.59，粗糙度 30.68 dB。同一网格上 albedo 比单 albedo 模型低约 0.3 dB，多学两个通道只带来很小的损失。

训练时每组在自己的切分网格上评测，D 的网格更细，不能和其他组放在一张图里直接比。起点为 100k 权重在对应网格上的重评值。

2.4 逐组结论

  • A（91 点输入）：三套网格都低 0.1 dB 左右，资产中位数低 0.6 dB。编码器多看 3 倍的点没有帮助，输入采样密度不是瓶颈。
  • C（格点 IO）：前期落后 0.6 dB，30k 时追平到 −0.1 / −0.3 dB，没有超过原始的注意力池化 + 逐点 MLP。
  • D（1/16384 切分训练）：训练时看起来比其他组高约 0.4 dB，全部来自评测网格更细（const 也高 0.24 dB）。同网格比较，D 在 1/16384 上 25.42，B 直接在 1/16384 上推理 25.53。更细的切分用在推理时就够了，不需要重训。
  • E（混合采样）：面积 PSNR 在原始 mesh 上和 B 持平、切分网格上 −0.1 dB；资产中位数在切分网格上略高 0.1 dB、原始 mesh 上低 0.2 dB，整体在噪声内。

三个评测集的含义：

  • val32：验证集列表（objaverse_val.txt，共 1,207 个 mesh，训练从未见过）的前 32 个 mesh。训练过程中每 2,500 步用它评测一次，本页的训练曲线、A–E 的统一重评都用这一组，是各实验之间对比的主要依据。
  • held-out 63：训练结束时，取同一个验证集列表的前 64 个 mesh 评测（结果存在 final.json）；其中 1 个（原 113,056 面）在大面切分后超过验证集 13 万面的上限被跳过，实际 63 个。它包含 val32 的那 32 个，再加 31 个，样本更多、更稳，同样是训练没见过的 mesh。
  • 训练集 64：训练结束时，取训练集列表（objaverse_train.txt，共 119,318 个 mesh）的前 64 个评测。这些 mesh 训练时见过，衡量的是拟合程度而不是泛化；它和 held-out 的差距（约 3 dB）反映泛化差距。

三组 mesh 不同，const 也不同（25.08 / 26.76 / 28.19），所以不同评测集之间的绝对数值不能直接比，只能在同一评测集内比较 100k 与退火。

3.3b 基线：TRELLIS.2 纹理 VAE 的评测方式

  • 模型：TRELLIS.2（Microsoft，arXiv 2512.14692）官方发布的纹理 SC-VAE（tex_enc / tex_dec_next_dc_f16c32），稀疏 3D 卷积 U-Net，输入 6 通道（albedo、金属度、粗糙度、alpha），空间下采样 16 倍，每个 latent 32 维。直接用官方权重推理，没有在 Objaverse 上重训。
  • 输入：用其官方 o-voxel 工具（textured_mesh_to_volumetric_attr，与 data_toolkit/voxelize_pbr.py 相同的归一化）把 GLB 体素化为 1024³ 的表面体素，编码取后验均值、再解码，得到每个表面体素的重建属性。中位数每个 mesh 2.0M 个体素、6.4k 个 latent（×32 维，约 204k 个数），C5VAE 固定 8192 个 latent × 64 维（524k 个数）。
  • 打分：在和 C5VAE 完全相同的点上取值——同样的 mesh、同样的 1/16384 切分、每面同样的 91 个格点、同样的面积加权公式；格点位置按 TRELLIS 的方式归一化，用三线性插值在稀疏体素上取值（与其官方贴图烘焙用的 flex_gemm grid_sample_3d 一致，误差 < 3e-5）。
  • 体素化 GT（上限）：同样方式直接读体素化后的真值属性，衡量 1024³ 体素表示本身丢掉了多少（一个体素会平均多个纹素）：val32 上 albedo 28.43 dB，TRELLIS.2 重建不可能超过它。

结论：TRELLIS.2 纹理 VAE 在所有指标上都明显好于 C5VAE_100k_anneal：val32 面积 PSNR 26.80 对 24.63（+2.2 dB），albedo +2.1，资产中位数 +4.3；held-out 63 上差距相近（面积 +2.4 dB）。它离自己的体素化上限只差约 1.2 dB，瓶颈主要在 1024³ 体素化本身；C5VAE 的面积 PSNR 还低于 const（25.08），瓶颈在模型。需要注意两点：（1）TRELLIS.2 的 latent 数量随表面积变化（这 64 个 mesh 中位数 6.4k、最多 23.0k，每个 32 维），C5VAE 固定 8192 个 × 64 维；（2）TRELLIS.2 用官方权重、未在 Objaverse 上重训，其训练数据规模更大，Objaverse 资产可能包含在其训练集里。续训到 200k 的 EMA 模型（3.7 节）把 val32 的差距缩小到 1.5 dB（26.80 对 25.33），held-out 63 上 1.4 dB；金属度已反超（34.63 对 33.94）。

3.11 单个 latent token 在 mesh 上的作用范围

问题：像 2D 里看 attention map 那样，一个 latent 到底影响 mesh 的哪一片？两种看法，都在救护车上用 237k 无 KL 续训的 EMA 权重、训练设置的 8192 锚点：（1）attention：解码端面角点 → latent 的 cross-attention 里，每个面对选定 token 的 softmax 权重（16 头平均），按面画热力图；（2）knock-out：把该 token 换成所有 latent 的均值再解码，看每个面 albedo 误差的增量。knock-out 又分两种：整链路（替换后走完 12 层 latent 自注意力再读出）和只屏蔽读出（latent 上下文不变，只是面不能读这个 key），后者分离出该 token 的直接贡献。解码是确定性的（同一输入解码两次误差差异为 0），所以误差增量图上的每一点都是真实影响。挑了 4 个 token：锚点所在面的输入纹理 std 最高的、前 2.5% 的、中位数的、最平坦的。
